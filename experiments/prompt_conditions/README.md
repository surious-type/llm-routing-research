# Prompt conditions E1-E4

E1-E4 — условия одного эксперимента: меняются семантика букв A/B и положение определения A в prompt.

Запуск:
~~~bash
python -m experiments.prompt_conditions.run --model Qwen/Qwen3-4B-AWQ
~~~

Основные параметры: --dataset, --routes, --model, --base-url, --limit, --output, --json-output.
